01 SQL · ITSM Analytics

Incident SLA Breach Analysis

The Ops team suspected SLA breaches were being under-reported in ServiceNow exports. I ingested a 5,200-row raw dataset riddled with duplicates, mixed date formats, and null timestamps — and rebuilt breach reporting from scratch using pure SQL before the next executive review.

02 Python · ETL Pipeline

Change Management ETL Pipeline

Built an end-to-end Python ETL pipeline replacing a manual 3-hour monthly review process. Extracts messy 5,600-row change request CSVs, applies multi-format date parsing and normalization, loads to SQLite, and auto-generates a severity-tiered data quality report.

◆301 duplicate change_ids detected and deduplicated before any analysis ran
◆~2,674 records flagged as missing approver — a HIGH severity compliance risk
◆11 distinct issue types auto-classified into HIGH / MEDIUM / LOW severity tiers
◆Pipeline is idempotent — safe to re-run without duplicating warehouse data

Cohort Retention & Trend Analysis

Full analyst workflow — SQL cleaning → Python automation → 3-page Power BI executive dashboard — answering which onboarding cohorts retain best and where SLA performance is trending. Raw data: 5,700 rows across 18 cohorts spanning 18 months.
